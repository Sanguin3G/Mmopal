# core.SendString

## Description

The `core.SendString` function sends a string of characters as if they were typed on the keyboard.

## Parameters

- **`text`** (string): The string of characters to send as keyboard input.

## Return value

- **`void`**: The function does not return any value.

## Example

```lua
core.SendString("test")  -- Sends the string "test" as keyboard input
```
