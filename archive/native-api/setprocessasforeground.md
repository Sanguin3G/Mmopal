# core.SetProcessAsForeground

## Description

The `core.SetProcessAsForeground` function brings the specified process's window to the foreground.

## Parameters

- **`process_name`** (string): The name of the process to bring to the foreground.

## Return value

- **`void`**: The function does not return any value.

## Example

```lua
core.SetProcessAsForeground("notepad.exe")
```
