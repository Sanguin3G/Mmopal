# core.CopyToClipboard

## Description

The `core.CopyToClipboard` function copies the specified text to the system
clipboard. This allows the text to be pasted into other applications.

## Parameters

- **`text`** (string): The text to be copied to the clipboard.

## Return value

- **`void`**

## Example

```lua
core.CopyToClipboard("Hello, World!")
```
