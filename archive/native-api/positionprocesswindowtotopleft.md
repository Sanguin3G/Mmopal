# core.PositionProcessWindowToTopLeft

## Description

The `core.PositionProcessWindowToTopLeft` function moves the window of the specified process to the top-left corner of the screen.

## Parameters

- **`process_name`** (string): The name of the process whose window you want to position.

## Return value

- **`void`**: The function does not return any value.

## Example

```lua
core.PositionProcessWindowToTopLeft("notepad.exe")
```
